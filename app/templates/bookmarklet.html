Manual Installation

  1. Create a new bookmark in your browser.
  2. Name it "Summarize YT" (or whatever you prefer).
  3. Copy the code below and paste it into the "URL" or "Location" field.

Browser Extension (Beta)

For the best experience, install our browser extension to get a "Summarize" button directly on YouTube video pages.

  1. Go to chrome://extensions (or edge://extensions).
  2. Enable Developer mode in the top right.
  3. Click Load unpacked.
  4. Select the extension folder in your project directory.
