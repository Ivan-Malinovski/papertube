Installation Instructions

1

Download the Extension

Click the "Chrome / Edge / Brave" download button above to get the extension ZIP file.

2

Extract the ZIP File

Extract the downloaded ZIP file to a folder on your computer. Remember the location of this folder.

3

Open Extensions Page

Type chrome://extensions in your browser's address bar and press Enter.

4

Enable Developer Mode

Look for a toggle switch labeled "Developer mode" in the top right corner and turn it on.

5

Load the Extension

Click the "Load unpacked" button and select the extracted extension folder.

6

Configure & Use

Click the extension icon in your browser toolbar, enter your Papertube credentials, and you're ready to go!

1

Download the Extension

Click the "Firefox" download button above to get the extension ZIP file.

2

Extract the ZIP File

Extract the downloaded ZIP file to a folder on your computer. Remember the location of this folder.

3

Open Firefox Debugging

Type about:debugging#/runtime/this-firefox in your browser's address bar and press Enter.

4

Load the Extension

Click the "Load Temporary Add-on" button and select the manifest.json file from the extracted folder.

5

Configure & Use

Click the extension icon in your browser toolbar, enter your Papertube credentials, and you're ready to go!

Note

Since this extension is not published to the official browser stores, you'll need to reinstall it if you clear your browser data. The extension works on Chrome, Edge, Firefox, Brave, and other Chromium-based browsers.
